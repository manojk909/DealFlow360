Governance — configuration, not code

  • CategoryDiscountCeiling tier × category → max %
  • ApprovalChainRule score band → Manager? Finance?

Effective ceiling for a line = min(tier, category). Edit either row in the admin and the next quotation routes differently, with no code change.

Quotation to cash — and the loop back through governance

The one idea worth taking away. Every line is scored against the stricter of its customer-tier ceiling and its category ceiling, and the quotation's blended risk score is the total points given away above ceiling. That number is matched against ApprovalChainRule rows to decide who reviews the deal. The rep never requests approval, and the customer's counter-offer re-enters the same routing on its own — both are the same code path, not two features that look alike.
